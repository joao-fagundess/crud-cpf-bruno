# CRUD CPF — Express + JSON Server

CRUD hospedado com Node.js, Express e JSON Server. Busca de registros por CPF.

## Rodar localmente

```bash
npm install
node server.js
```

Abra `http://localhost:3000`.

## Render

- **Build Command:** `npm install`
- **Start Command:** `node server.js`

O Render define a porta em `PORT`; o `server.js` já usa `process.env.PORT`.
